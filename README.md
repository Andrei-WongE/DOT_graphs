# Conceptual models of boundaries and segregation. 

Ontological differences are perceived and transformed into social facts, progressing from the individual to the group level. 

Tangible manifestations of boundaries are domain-specific and enforce domain-specific modulation of interactions:

           * Morphological: A physical division (e.g., highway, river).
           * Political: An administrative or legal rule (e.g., zoning law).
           * Social: An obstacle in social networks (e.g., lack of bridging ties).
           * Functional: A gap in urban systems (e.g., no public transport link).
           * Symbolic: Collective semiotic demarcations (e.g., flags, murals, architecture).

What is measurable is the underlying discontinuity, quantified by using edge detection models.
